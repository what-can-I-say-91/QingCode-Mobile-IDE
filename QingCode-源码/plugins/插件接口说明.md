# QingCode 插件接口说明（PCPluginAPI v2）

> 插件接口自 v4.4 起预留、v4.6 升级 v2（新增插件管理页自定义选项卡 `page()`、meta 标准字段与插件启停；**v1 插件无需修改即兼容**）。宿主只提供加载与底层通道，**插件由你自行开发**。

**[中文](插件接口说明.md) · [English](Plugin-API-Guide_EN.md)**

## 一、插件是什么、放哪里

- 一个插件 = 一个 `.js` 文件（普通 JavaScript，非 ES Module）；
- 放到手机目录 **`/sdcard/QingCode/plugins/`**（没有就新建），应用启动时自动按文件名顺序加载；
- 加载方式：`new Function('PCPluginAPI', 源码)(PCPluginAPI)`——插件里通过参数 `PCPluginAPI` 访问宿主能力，不污染全局；
- 插件抛错只影响自己（终端里输出 `[插件] 加载失败：…`），不影响主程序；
- 无存储权限或目录为空时自动跳过，零开销。

## 二、注册插件

```js
// /sdcard/QingCode/plugins/hello.js —— 最小示例
PCPluginAPI.register({
  id: 'hello',            // 必填，唯一 ID（重复注册会被忽略）
  name: 'Hello 插件',
  version: '1.0',
  author: '你的名字',            // v2 标准字段：显示在插件管理页
  description: '一句话介绍插件',  // v2 标准字段：显示在插件管理页
  homepage: 'https://…',         // v2 可选：主页/仓库链接
  menu: [                 // 可选：注册「更多菜单」项
    { label: 'Hello 世界', onClick: (api) => api.toast('Hello, QingCode!') },
  ],
  onInit(api) {           // 可选：所有文件加载完成后回调一次
    api.out('[hello] 插件已就绪\n');
  },
  onUnload(api) {         // v2 可选：禁用/卸载回调（当前禁用=重启生效，此回调为未来热卸载预留）
  },
});
```

## 三、语言类插件（运行其他语言）

两步：`register()` 里声明 `languages`（扩展名进「新建文件」白名单），再提供 `onRun` 运行钩子。
点 ▶ 运行时，文件扩展名命中插件语言 → 交给插件 `onRun` 自行编排。

```js
// /sdcard/QingCode/plugins/lua.js —— Lua 语言插件（示例）
PCPluginAPI.register({
  id: 'lua',
  name: 'Lua',
  version: '1.0',
  languages: [{
    id: 'lua',
    name: 'Lua',
    exts: ['.lua'],                       // 支持哪些扩展名
    defaultCode: 'print("Hello, Lua!")',  // 可选：新建文件默认代码
    comment: '--',                        // 可选：行注释符
  }],
  async onRun(file, code, langDef, api) {
    // 1. 把代码写到交换目录（Termux 侧可读）
    if (!api.writeSwapFile('plug_main.lua', code)) {
      api.out('写入交换目录失败（检查存储权限）\n', 'out-err'); return true;
    }
    // 2. 确保 Termux 里有解释器（缺则自动安装）
    await api.runCapture('command -v lua >/dev/null || pkg install -y lua');
    // 3. 运行并捕获输出
    const r = await api.runCapture('lua /sdcard/QingCode/plug_main.lua');
    api.out(r.output, r.code === 0 ? 'out-echo' : 'out-err');
    api.meta('Lua 运行结束，退出码 ' + r.code);
    return true;   // 返回 true 表示已接管本次运行
  },
});
```

运行前置：Termux 已安装并完成「设置 → 引擎与 Termux → ⚙️ 配置 C++」的初始化（脚本里 `pkg install` 依赖清华源）。首次运行某语言会自动装解释器，耗时稍长。

## 四、API 参考

| API | 说明 |
|---|---|
| `register(meta)` | 注册插件（重复 ID 忽略）；`meta` 字段见上文 |
| `out(text, cls?)` | 向终端追加输出；cls：`out-echo` 普通 / `out-err` 错误（默认普通） |
| `meta(text)` | 状态栏消息 |
| `toast(msg)` | 安卓 Toast 弹窗 |
| `execTermux(script, background=true)` | **底层原语**：向 Termux 发送任意脚本，立即返回是否发出成功；输出重定向/轮询由插件自理 |
| `runCapture(script)` | **高层封装**：执行脚本并捕获 stdout+stderr，返回 `Promise<{code, output}>`（输出重定向到交换目录临时文件 + 轮询 + 自动清理，120 秒超时） |
| `writeSwapFile(name, content)` | 写交换目录 `/sdcard/QingCode/` 下文件（防路径穿越：名字仅限字母数字点下划线横线，禁 `..`） |
| `readSwapFile(name)` | 读交换目录下文件，不存在返回 `''` |
| `deleteSwapFile(name)` | 删除交换目录下文件 |
| `copy(text)` | 复制到剪贴板 |
| `storage(id)` | 隔离键值存储：`get(key, dft)` / `set(key, val)` / `del(key)`（localStorage，键自动加 `pc_plugin_<id>_` 前缀） |
| `page(tabId, def)` | **v2 新增**：向「插件管理页」注册自定义选项卡，`def = { title, render(container, api) }`；`render` 在切到该选项卡时惰性调用，`container` 为内容容器，可自由填充 DOM；返回是否注册成功（内置选项卡 id `loaded`/`langs`/`settings` 不可覆盖） |
| `apiVersion` | 接口版本，当前 `2`（不兼容变更时递增） |

## 五、插件管理页扩展（v4.6）

「更多菜单 → 🧩 插件管理」是插件的管理中心（顶部选项卡：**已加载 / 语言 / 设置**），插件可以做三件事：

### 1. 追加自定义选项卡

```js
PCPluginAPI.register({
  id: 'mytool',
  name: 'MyTool',
  version: '1.0',
  onInit(api) {
    // 向插件管理页注册一个「我的工具」选项卡
    api.page('mytool', {
      title: '我的工具',
      render(container, api) {
        // container 是页面的内容容器（div），每次切到该选项卡都会重新调用
        const btn = document.createElement('button');
        btn.textContent = '点击运行';
        btn.onclick = () => api.toast('来自插件选项卡！');
        container.appendChild(btn);
      },
    });
  },
});
```

### 2. 展示元信息

`register` 里的 `name` / `version` / `author` / `description` / `homepage` 会自动显示在「已加载」选项卡的插件卡片上。

### 3. 启用 / 禁用（用户操作）

- 管理页「已加载」选项卡每张卡片带**启用/禁用**按钮：禁用按**文件名**记忆（`localStorage('pc_plugins_disabled')`），重启应用后不再加载；
- 「设置」选项卡有**插件系统总开关**（`pc_plugins_enabled`），关闭后启动时跳过所有插件；
- 启停状态切换会弹 Toast 提示「重启应用后生效」；被禁用而未加载的插件也会以「已禁用」卡片列出，可随时重新启用。

## 六、注意事项

- 插件运行于前端 WebView 环境，能力边界即 `PCPluginAPI` 提供的通道；不要绕过 API 操作主程序内部状态（内部实现随时可能调整）；
- `onRun` 目前为同步调用：长任务请用 `async` 函数并在内部 `await`；运行按钮的「停止」暂不接管插件运行（接口 v1 预留范围）；
- `runCapture` 超时 120 秒；交互式程序（需要 stdin）请用 `execTermux` 自行编排或引导用户用「在 Termux 终端运行」；
- 示例骨架见 `plugins/example-lang-plugin.js`（注释详尽，改名放入 plugins 目录即可启用）。
