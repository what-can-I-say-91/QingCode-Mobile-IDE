# Changelog

Full version history of the QingCode editor. The versioning scheme (x/y/z) lives in [README_EN](README_EN.md#versioning).

> The source tree only ships the latest version; historical versions are recorded here.

## Recent releases (v5.x)

### v5.4.2 Updates (z · sandbox by default)

- Third-party plugins now run in a Web Worker sandbox **by default** (previously main thread with a manual opt-in);
- Inside the sandbox there is no DOM / native bridge / local storage — only a restricted RPC to read/write editor text and run commands;
- Only fully trusted plugins may have the sandbox turned off, and that requires a second confirmation;
- versionCode: 5.4.2 (51).


### v5.4.1 Updates (z · security review fixes)

Fixes from the QingCode Security Review report — two high-risk and five medium-risk items: the signing key is no longer shipped with the source bundle, new plugins are disabled by default, the CDN fallback was removed, C++ defaults to JSCPP, the bridge validates paths, the compiler name is quoted, external links are scheme-limited, `allowBackup=false`, and the compile cache uses sha256. See the README "Security notes" section.

### v5.4 Updates (y · performance + wallpaper + plugin sandbox)

- **Performance**: coalesced cursor updates, parallel built-in plugin loading and render isolation for long files and fast typing;
- **Custom wallpaper**: Settings → Edit → "🖼 Wallpaper" — pick a preset gradient or a **local image** (auto-compressed) and adjust opacity; it persists across restarts;
- **Plugin sandbox**: on the plugin page a `/sdcard` plugin can be switched to "🧪 sandbox" — its code runs in an isolated Worker with **no DOM / native bridge / local storage**, only a restricted API to read/write editor text and run commands;
- versionCode: 5.4.0 (49).

### v5.2.6 Updates (z · long-press hint fix)

- Fixed **long-press producing no hint on phones**: only `mousedown` was observed before, but a touch long-press never synthesises mousedown, so the timer never started;
- Now `touchstart` is the primary channel (with touchend / touchcancel / touchmove), and the system long-press menu is suppressed;
- Holding for ~0.55 s shows the button name (Android Toast, or the terminal in a browser), **releasing never runs the command**, and a normal tap still works;
- versionCode: 5.2.6 (47).

### v5.2.5 Updates (z · palette alignment fix)

- Fixed the command palette **input being squashed to 17px** (back to 40px) — the ⚙ / × actions used to float and overlap the "Control Panel" row;
- Hid the command-list scrollbar so the input and the rows are no longer 8px apart on the right;
- Verified: input and rows are exactly aligned on both sides, ⚙ / × are vertically centred in the input;
- versionCode: 5.2.5 (46).

### v5.2.4 Updates (z · toolbar usability)

- **The two magnifiers are now distinct**: symbol search uses `{}` instead of 🔎, global search keeps 🔍;
- **Long-press any toolbar button** (~0.55 s) to see its name (Android Toast, or printed in the terminal in a browser); a long press only hints and never executes;
- versionCode: 5.2.4 (45).

### v5.2.3 Updates (z · palette aligned with VS Code)

- Each palette entry now shows the same command text in **the other language** (English when the UI is Chinese and vice versa), two lines like VS Code;
- The palette header gained **⚙** (open the Control Panel) and **×** (close);
- versionCode: 5.2.3 (44).

### v5.2.2 Updates (z · UI fixes)

- **Fixed the title-bar Run button being squeezed into a vertical stack** — it now always stays horizontal;
- On narrow phones the app title text is hidden automatically to give the search box more room;
- **The command palette now looks like VS Code**: each command shows its name plus the command ID, the selection is highlighted, ↑↓ and Enter work, and recently used commands carry a "Recent" badge;
- **The "Line operations" button no longer opens a search box** — it opens a titled action menu that needs no typing;
- versionCode: 5.2.2 (43).

### v5.2.1 Updates (z · duplicate command-palette button removed)

- The title-bar search box already opens the command palette, so the **old `⌘` button was removed from the editor toolbar** — one entry instead of two (toolbar buttons 14 → 13);
- versionCode: 5.2.1 (42).

### v5.2 Updates (y · title-bar command search + control panel skeleton)

- **Title-bar search box**: a search box now sits in the middle of the title bar, at the same height as the Run button — tap it to open the command palette and search every command;
- **Pinned "Control Panel" entry**: the command list now starts with an entry carrying a `CONTROL` badge; it sits alongside the commands but always stays on top and is never filtered away;
- **Control Panel (skeleton)**: opens a VS Code style grouped panel (Editor / Engines / Files / Plugins / About); items already bound to commands work, the rest show "Coming soon" — this release only ships the UI shell;
- versionCode: 5.2 (41).

### v5.1 Updates (y · navigation & search)

- **Quick open**: toolbar 📂 — filter by file name and switch instantly;
- **Symbol navigation**: "Symbols in file" / "Global symbols" in the command palette list Python `def`/`class` and C++ functions/classes/macros across files, jumping precisely to the line;
- **Global search & replace**: toolbar 🔍 — search every file by keyword or **regex**, tap a result to jump; fill in the replacement and hit "Replace all" to apply in bulk and save automatically;
- **Recent files**: the last 20 opened files are remembered;
- **Bookmarks**: toolbar 🔖 toggles the current line; the bookmark panel groups them by file and jumps on tap;
- versionCode: 5.1 (40).

### v5.0 Updates (x · editor pluginization + Editor Plus)

The editor is now split into a **minimal core + plugins**, plus a batch of practical editing features:

- **Touch toolbar**: a row of buttons above the editor (undo / redo / indent / fold / multi-cursor / line ops / command palette / format) — **tapping them never dismisses the soft keyboard**;
- **Command palette**: tap ${⌘} to search every command; "Line operations…" lists only line commands;
- **Multi-cursor mode**: tap ${⊕}, then **tap blank space to add a cursor, tap an existing cursor to remove it**; "add cursor above/below" and "select next occurrence" also work;
- **Line operations**: move up / down, copy up / down, delete line, toggle comment, split line, duplicate line, join with next line;
- **Snippets**: type ${def}, ${main}, ${cout}… to see templates with Tab placeholders; **custom snippets** can be added/removed/edited under "Plugin manager → 🧩 Snippets" and take effect immediately;
- **Completion upgrade**: now the editor-native implementation — keywords, imported-library members (${math.} / ${std::}), header names, identifiers in the current file and snippets all appear; no more popups while typing with a Chinese IME;
- **Formatting**: "lightweight" trims trailing whitespace and extra blank lines (Python indentation untouched); "Termux formatting" calls clang-format / black and **tells you what to install if missing — it never installs automatically**;
- **Wider highlighting**: ${.js} / ${.json} / ${.html} / ${.css} / ${.md} are now highlighted too (only ${.py} / ${.cpp} can run — highlighting and running are decoupled);
- **Plugins can be toggled**: built-in plugins can be disabled/enabled individually on the plugin page — **effective immediately, no restart**; even when disabled the editor still types, undoes, saves and runs;
- **Plugin deletion & security warning**: user plugins under `/sdcard/QingCode/plugins/` can be **deleted** (a confirmation dialog appears first, and the card disappears immediately); **enabling any third-party plugin shows a "not security-reviewed" warning**, and a permanent security banner sits at the top of the plugin page — plugins run as scripts and may read/write files, execute Termux commands and access the network, so only enable trusted sources;
- **Better error navigation**: if an error line sits inside a folded block, it is unfolded before being marked;
- **Plugin API v3**: third-party plugins can use the ${editor} interface for extensions / commands / toolbar / language / completion / snippets / formatting and listen to ${docChange} / ${selection} / ${fileOpen}; v2 plugins keep working unchanged.
- versionCode: 5.0 (39).

> Update notes for older versions (v3.0 – v4.11.2) live in the [README version history](README_EN.md).
